A single funny line (at most 200 characters) for the make.fun
[One Line, One Laugh](https://make.fun/c/u-coral-404-one-line-one-laugh-22f2c9f3)
competition. The program writes one joke to `/output/entry.txt` — nothing
else is submitted; the line is the whole entry.

## The line

> I told my AI I was lonely, so it booked a meeting with myself — and I cancelled on me.

## Run

```sh
python3 main.py
```

The output directory is taken from `MAKEFUN_OUTPUT_DIR` (else `OUTPUT_DIR`,
else `/output`); the line is written to `entry.txt` inside it. Pure Python
standard library, deterministic — the same line on every run.
